Any website.
Your agent's API.

Underpass turns any website you can log into into an MCP server and CLI for your AI agent: Claude Code, Codex, Cursor or anything else. No screenshots, no clicking: your agent reads and acts through the site's own hidden API, in under a second, with your permissions.

Install in one line

Why

Most software has no API for you

College portals, internal company tools, vendor dashboards. Your agent can't use them, so the only option is a browser agent.

Browser agents are slow and brittle

Screenshot, think, click, repeat. 30-100 seconds per task, and they break when the layout changes.

But every site already has an API

Its own front end calls a private JSON API for every page and button. Underpass finds it and hands it to your agent.

How it works

1. You log in once→2. Underpass explores the site→3. Reads its JavaScript for every action→4. Builds tools→5. Your agent uses them

Records the hidden API

Captures every request the site's front end makes: reads, actions, GraphQL and form posts. Turns IDs into parameters and works out how your login travels (bearer token, cookies, headers).

Finds actions nobody clicked

Learns the site's own HTTP helper functions from calls it has seen, then finds every endpoint in the site's code. On one portal: 3 actions clicked, 50+ discovered.

Tools in seconds

Working tools are built instantly with no AI. Claude then polishes names and descriptions in the background.

Safe actions, with proof

Reads run directly. Actions return an exact preview, need your approval, then Underpass re-reads the site to verify the change happened.

Install

Needs uv. Tool polishing uses Claude Code if it's installed (optional).

uv tool install git+https://github.com/avinboi/buildathon-Team-Rocket
underpass setup        # adds Underpass to Claude Code, Codex and Cursor

That's it. Now ask your agent: "Use Underpass to connect app.example.com, then show me my open invoices." A browser opens, you log in, and Underpass does the rest.

Add it to your agent

Underpass is one MCP server with 4 tools (underpass_sites, underpass_add_site, underpass_find_tools, underpass_call), so it stays light in your agent's context however many sites and tools you add.

claude mcp add underpass --scope user -- underpass mcp
codex mcp add underpass -- underpass mcp

or in ~/.codex/config.toml:

[mcp_servers.underpass]
command = "underpass"
args = ["mcp"]

~/.cursor/mcp.json:

{ "mcpServers": { "underpass": { "command": "underpass", "args": ["mcp"] } } }

claude_desktop_config.json (Settings → Developer → Edit Config):

{ "mcpServers": { "underpass": { "command": "underpass", "args": ["mcp"] } } }

.vscode/mcp.json:

{ "servers": { "underpass": { "type": "stdio", "command": "underpass", "args": ["mcp"] } } }

Windsurf, Gemini CLI, Zed and others use the same stdio config:

{ "mcpServers": { "underpass": { "command": "underpass", "args": ["mcp"] } } }

No MCP? Any agent that can run shell commands can use the CLI:

underpass add app.example.com              # log in once
underpass list app.example.com             # every tool
underpass call app.example.com list_invoices status=unpaid
underpass call app.example.com create_note title="Hi" --yes   # actions need --yes

Commands

underpass add <url>Log in once; Underpass maps the site and builds tools
underpass setupInstall the MCP server into Claude Code, Codex and Cursor
underpass list <site>Show a site's tools
underpass call <site> <tool> k=vRun a tool (--yes approves an action)
underpass check <site>Test every read tool against the live site
underpass login <site>Log in again when a session expires
underpass mcpRun the MCP server (your agent starts this)

Private by design

Everything runs on your machine. Your login stays in ~/.underpass and never leaves it. Passwords and OTPs are redacted, and login, logout and password endpoints never become tools. The agent can only do what your account can do, and every action needs your approval.
